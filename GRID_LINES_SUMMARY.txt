🎯 FEATURE IMPLEMENTED
======================

Grid lines are now drawn between ALL rows and columns when using the --pp or -p
pretty-print flags. This creates a professional spreadsheet-like table layout.

Feature: Full grid with horizontal separators between data rows
Flags: --pp or -p (pretty-print)
Status: ✅ IMPLEMENTED, TESTED, AND VERIFIED

💡 IMPLEMENTATION NOTES
=======================

The grid lines are drawn by:

1. After printing the header row:
   - Print a separator line with left junction (├), cross junctions (┼),
     right junction (┤), and horizontal line (─)

2. After printing each data row:
   - Print the same style separator line
   - Skip the separator after the last row (bottom border uses └─┴─┘)

The separator is printed using the existing print_separator() function with
box-drawing characters:
  - Left: ├  (left junction)
  - Right: ┤  (right junction)
  - Cross: ┼  (cross junction)
  - Horizontal: ─ (horizontal line)
