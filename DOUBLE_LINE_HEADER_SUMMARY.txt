QUICK SUMMARY
================================================================================

What Changed:
  The separator line directly below the header now uses double-line characters
  (═╬═) instead of single-line characters (─┼─).
  
  This creates a clear visual distinction between the header and data rows.

Before:
  ┌─────────┬─────┬────────────┐
  │ Name    │ Age │ City       │
  ├─────────┼─────┼────────────┤  ← Single line
  │ Alice   │  30 │ NewYork    │

After:
  ┌─────────┬─────┬────────────┐
  │ Name    │ Age │ City       │
  ╠═════════╬═════╬════════════╣  ← Double line (NEW!)
  │ Alice   │  30 │ NewYork    │

================================================================================
VISUAL COMPARISON
================================================================================

Box-Drawing Characters Used:

Header Separator (Double Lines):
  ╠═══════════════════╣
  └─ ╠ = Left junction with double line
  └─ ═ = Horizontal double line
  └─ ╬ = Cross junction with double line (between columns)
  └─ ╣ = Right junction with double line

Data Row Separators (Single Lines):
  ├───────────────────┤
  └─ ├ = Left junction with single line
  └─ ─ = Horizontal single line
  └─ ┼ = Cross junction with single line (between columns)
  └─ ┤ = Right junction with single line

Border (Outer):
  ┌───────────────────┐
  └─ ┌ = Top-left corner
  └─ ┐ = Top-right corner
  └─ └ = Bottom-left corner
  └─ ┘ = Bottom-right corner
